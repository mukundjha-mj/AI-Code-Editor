Implement Part 6: Visual Graph Engine.

Current Status:

* Foundation Layer complete.
* AI Infrastructure complete.
* Repository Intelligence complete.
* Monaco Workspace complete.
* Explain My Codebase complete.

Repository intelligence already provides:

* Files
* Symbols
* Dependencies
* Component relationships
* Route metadata
* Context retrieval

Objective:

Build an interactive visual graph system that allows users to understand repository structure visually.

Do not implement Intent Mode yet.

Requirements:

1. Graph Engine

Create a graph visualization infrastructure.

Support:

* Nodes
* Edges
* Groups
* Clusters
* Layouts

The graph engine should be reusable for multiple graph types.

2. Graph Types

Support the following views:

A. File Graph

Display:

* Files
* Imports
* Exports
* Dependency relationships

Questions answered:

* What imports this file?
* What does this file depend on?

B. Component Graph

Display:

* Parent components
* Child components
* Shared components

Questions answered:

* Which component renders this?
* What does this component render?

C. Route Graph

Display:

* Routes
* Entry points
* Feature boundaries

Questions answered:

* How is navigation structured?

D. Module Graph

Display:

* Modules
* Services
* Shared layers

Questions answered:

* What systems communicate with each other?

3. Graph Data Layer

Create graph transformation services.

Convert repository intelligence data into graph models.

Do not expose raw repository structures directly to the UI.

4. Interactive Navigation

Support:

* Zoom
* Pan
* Node selection
* Edge selection
* Focus mode
* Search

5. Monaco Integration

Clicking a graph node should:

* Open file
* Open component
* Focus symbol

6. Explain Integration

Users should be able to:

* Select graph node
* Open Explain panel

The graph becomes a navigation layer for explanations.

7. Graph API

Create endpoints:

GET /api/v1/graph/files
GET /api/v1/graph/components
GET /api/v1/graph/routes
GET /api/v1/graph/modules

Return graph-ready data.

8. Large Repository Support

Support:

* Thousands of files
* Graph filtering
* Node collapsing
* Lazy graph loading

Avoid rendering entire repositories at once.

9. UI Layout

Create a dedicated Graph Workspace.

Support:

* Graph panel
* Detail panel
* Explain integration
* Monaco integration

10. Important Constraints

Do not implement:

* Intent Mode
* Decision Memory
* AI Code Editing
* AI Refactoring
* AI Patch Generation

This phase focuses only on visual understanding.

Goal:

A user should be able to visually explore:

* Repository architecture
* Dependencies
* Components
* Routes
* Relationships

without reading raw code.
