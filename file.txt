Implement Part 4: Monaco Workspace Layer.

Current Status:

* Foundation Layer complete.
* AI Infrastructure complete.
* Repository Intelligence Engine complete.
* Backend APIs are operational.
* Frontend currently contains only the base React application.

Objective:

Build the editor workspace infrastructure using Monaco Editor.

This phase focuses only on editor functionality and workspace management.

Do not implement AI-assisted editing yet.

Requirements:

1. Monaco Editor Integration

Install and configure Monaco Editor.

Create a reusable editor module.

Support:

* TypeScript
* JavaScript
* TSX
* JSX
* JSON
* Markdown

Prepare architecture for future language extensions.

2. Workspace System

Create workspace management.

Support:

* Opening projects
* Opening files
* Closing files
* Active file tracking
* Multiple tabs
* Unsaved changes tracking

Maintain workspace state globally.

3. File Loading

Connect frontend to repository APIs.

Support:

* File tree loading
* Folder expansion
* File selection
* File content loading

Do not use mock data.

Use repository endpoints.

4. File Editing

Support:

* Editing files
* Save file
* Save all files
* Detect unsaved changes
* Reload file from disk

Prepare for future conflict handling.

5. Editor State Management

Track:

* Cursor position
* Selections
* Open tabs
* Scroll position
* Active editor

Persist editor state locally.

6. File Explorer

Create a file explorer panel.

Support:

* Folder tree
* Expand/collapse
* Search files
* Active file highlighting

Use repository intelligence data.

7. Diff Viewer

Configure Monaco diff editor.

Support:

* Original file
* Modified file
* Change visualization

Prepare for future AI patch review.

8. Editor Events Layer

Create a centralized event system.

Track:

* File opened
* File closed
* File saved
* Selection changed
* Cursor changed
* Content changed

Future AI modules will subscribe to these events.

9. Frontend Architecture

Create dedicated modules for:

* Workspace
* Editor
* File Explorer
* Diff Viewer
* Editor State
* Editor Events

Keep modules independent.

10. Performance Requirements

Support:

* Large files
* Many open tabs
* Lazy loading
* Virtualized file tree

Avoid unnecessary re-renders.

11. Important Constraints

Do not implement:

* AI Chat
* Intent Mode
* Explain My Codebase
* Decision Memory
* Code Generation
* AI Suggestions
* Inline Completions

This phase is strictly about editor infrastructure.

Goal:

Create a professional code editor experience similar to VS Code's core editing workflow, powered by Monaco Editor and connected to the repository intelligence backend.
