# Frontend

React + Vite + TypeScript foundation using Tailwind CSS v4.

## Commands

```bash
bun install
bun run dev
```

## Structure

- `src/app` app-level setup
- `src/components` reusable UI components
- `src/features` domain folders for editor/chat/explorer/graph/explanations/decision-memory/auth
- `src/hooks`, `src/services`, `src/store`, `src/types`, `src/lib`
- `src/styles/tailwind.css` Tailwind entry file

Copy `.env.example` to `.env` for local configuration.
